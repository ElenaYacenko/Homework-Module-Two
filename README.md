🔹 Пункт 0: Арифметика с int
Легенда: У воина есть базовый урон меча и бонус от силы.
Задача:
Объяви две переменные типа int (например, swordDamage и strengthBonus).
В отдельных строках или через промежуточные переменные выполни:
сложение (общий урон за удар)
вычитание (урон после наложения ослабления)

Ожидаемый вывод: 4 числа в консоль с поясняющим текстом, например: Общий урон: 45, Ударов для пробития брони: 3 и т.д.

🔹 Пункт 1: int + double в одном выражении
Легенда: Персонаж выпил зелье (+15.5% к урону) и надел зачарованные перчатки (+фиксированный бонус).
Задача:
Создай переменную double с множителем (например, 1.155 или 0.155 в зависимости от логики).
Напиши ровно одно выражение, которое: берёт int-урон, умножает на double-множитель и прибавляет int-бонус перчаток.
Сохрани результат в переменную и выведи её.
Технический фокус: Java автоматически выполняет promotion (продвижение типа). Подумай, какого типа должна быть переменная для хранения результата, чтобы не потерять дробную часть.
Ожидаемый вывод: Одно дробное число. Например: Итоговый урон с зельем и перчатками: 62.75

🔹 Пункт 2: Операторы сравнения (<, >, >=, <=)
Легенда: Система проверяет, может ли персонаж войти в подземелье и жив ли он.
Задача:
Объяви переменные level и health (типа int).
Выполни сравнения и сохрани результаты в boolean-переменные или выведи сразу:
уровень подходит для данжа? (>= 10)
уровень не превышает лимит локации? (<= 20)
здоровье строго больше нуля? (> 0)
здоровье меньше порогового значения для регенерации? (< 30)
Технический фокус: Результат любого из этих операторов — строго true или false. Их можно комбинировать через &&/||, но в рамках задания достаточно вывести каждое сравнение отдельно.
Ожидаемый вывод: Последовательность true/false. Например: Вход разрешён по уровню: true, Здоровье критическое: false и т.д.

🔹 Пункт 3: Диапазоны float/double и переполнение (теория + практика вывода)
Легенда: Справочник магических констант мира.
Задача:
Найди и выведи в консоль 4 константы: минимальное и максимальное значения для float и double.
В коде добавь многострочный комментарий /** ... */ или /* ... */, где своими словами ответь на два вопроса:
Как получить эти значения в Java? (подсказка: через классы-обёртки)
Чем отличается переполнение целого числа (int) от переполнения вещественного (double)?
Технический фокус: Обрати внимание, что у double есть специальные состояния: Infinity и NaN. При делении на 0.0 или выходе за диапазон они не "заворачиваются", как int.
Ожидаемый вывод: 4 больших числа в экспоненциальной записи (например, 3.4028235E38) + твой текстовый комментарий в коде.

🔹 Пункт 4: Демонстрация переполнения int
Легенда: Игрок нашёл сундук с бесконечным золотом, но инвентарь ограничен 32 битами.
Задача:
Создай переменную int и присвой ей максимально возможное значение для этого типа.
Прибавь к ней любое положительное число (например, 100_000 или даже 1).
Выведи результат и рядом напиши комментарий, объясняющий, почему знак числа изменился.
Технический фокус: В Java переполнение целых чисел не выбрасывает исключение по умолчанию. Происходит "wrap-around" из-за дополнительного кода (two's complement). Старший бит становится битом знака.
Ожидаемый вывод: Отрицательное число. Например: Золото после переполнения: -2147383648. + твой комментарий в коде.
