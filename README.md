# Основы Java

Домашнее задание по базовым операциям, типам данных и переполнению в Java.

## Список задач
0. Применить несколько арифметических операций (`+`, `-`, `*`, `/`) над примитивами типа `int`.
1. Применить несколько арифметических операций над `int` и `double` в одном выражении.
2. Применить несколько логических операций (`<`, `>`, `>=`, `<=`).
3. Изучить диапазоны типов данных с плавающей точкой (максимальные/минимальные значения, как их получить) и их переполнение.
4. Продемонстрировать переполнение при арифметической операции с `int`.

## Рабочий лист: `RPGCharacterMath.java`

### 🔹 Пункт 0: Арифметика с `int`
**Легенда:** У воина есть базовый урон меча и бонус от силы.  
**Задача:**
- Объявить переменные `int` (например, `swordDamage` и `strengthBonus`).
- Выполнить: сложение (общий урон), вычитание (урон после ослабления), умножение (урон за комбо из 3 ударов), деление (сколько ударов нужно, чтобы пробить броню врага).  
  **Технический фокус:** Деление `int` на `int` в Java всегда отбрасывает дробную часть. В коде применен хак `+ 1` для корректного округления в большую сторону (чтобы гарантированно пробить броню).  
  **Ожидаемый вывод:** 4 числа с поясняющим текстом. Например: `Hits to penetrate armor (int division): 2`.

### 🔹 Пункт 1: `int` + `double` в одном выражении
**Легенда:** Персонаж выпил зелье (+15.5% к урону) и надел зачарованные перчатки (+фиксированный бонус).  
**Задача:**
- Создать переменную `double` с множителем (например, `1.155`).
- Написать **одно выражение**, которое берет `int`-урон, умножает на `double`-множитель и прибавляет `int`-бонус перчаток.  
  **Технический фокус:** Java автоматически выполняет *type promotion* (продвижение типа). Результат выражения будет автоматически приведен к `double`, чтобы не потерять дробную часть.  
  **Ожидаемый вывод:** Одно дробное число. Например: `Total damage with potion and gloves: 22.325`.

### 🔹 Пункт 2: Операторы сравнения (`<`, `>`, `>=`, `<=`)
**Легенда:** Система проверяет, может ли персонаж войти в подземелье и жив ли он.  
**Задача:**
- Объявить переменные `playerLevel` и `playerHealth` (тип `int`).
- Использовать конструкцию `if`, объединяющую условия: уровень в диапазоне `[10, 20]` **И** здоровье строго `> 0`.  
  **Технический фокус:** Результат сравнений — строго `true` или `false`. Оператор `&&` требует выполнения обоих условий для входа в блок `if`.  
  **Ожидаемый вывод:** `You advance to the second level` (при успешной проверке) или `You failed, bro`.

### 🔹 Пункт 3: Диапазоны `float`/`double` и переполнение
**Легенда:** Справочник магических констант мира.  
**Задача:**
- Вывести в консоль константы `MAX_VALUE` и `MIN_VALUE` для `Float` и `Double` через классы-обёртки.
- Продемонстрировать переполнение (умножение `MAX_VALUE` на 2 или 10) и получение `NaN` (деление `0.0 / 0.0`).  
  **Технический фокус:** В отличие от `int`, при переполнении `double` не "заворачивается" в отрицательное число, а превращается в `Infinity`. Математическая неопределенность дает `NaN` (Not a Number).  
  **Ожидаемый вывод:** Числа в экспоненциальной записи (например, `3.4028235E38`), значения `Infinity` и `NaN`.

### 🔹 Пункт 4: Демонстрация переполнения `int`
**Легенда:** Игрок нашёл артефакт с огромным опытом, но инвентарь ограничен 32 битами.  
**Задача:**
- Создать переменную `int` и присвоить ей значение, близкое к максимуму (`Integer.MAX_VALUE - 50000`).
- Прибавить к ней `100_000`.
- Вывести результат до и после, продемонстрировав смену знака.  
  **Технический фокус:** В Java переполнение целых чисел не выбрасывает исключение. Происходит *wrap-around* из-за использования дополнительного кода (two's complement). Старший бит меняется с `0` на `1`, делая число отрицательным.  
  **Ожидаемый вывод:** Отрицательное число. Например: `Hero’s XP after artifact: -2147433649`.
